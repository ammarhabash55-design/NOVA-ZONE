# DIVINEX - Game Mods Library

موقع حديث ومتطور لمكتبة تعديلات الألعاب بتصميم معاصر وواجهة مستخدم احترافية.

## 📋 المميزات

- 🎨 تصميم حديث مع ألوان داكنة وأحمر وردي مميز
- 🔍 شريط بحث قوي للبحث عن التعديلات
- 🏷️ تصنيفات ذكية (شهيرة، جديد، ساخن، مميزة)
- 📱 متجاوب بالكامل (Responsive Design)
- ⚡ أداء سريع وسلس
- 🎮 عرض تفاصيلي لكل تعديل

## 📂 هيكل الملفات

```
project/
├── index.html           # الصفحة الرئيسية
├── game.html           # صفحة تفاصيل التعديل
├── search.html         # صفحة نتائج البحث
├── css/
│   └── style.css       # أنماط الموقع
├── js/
│   └── main.js         # سكريبتات جافا سكريبت
└── README.md           # هذا الملف
```

## 🚀 كيفية الاستخدام

1. افتح `index.html` في المتصفح
2. استخدم الفلاتر للبحث عن التعديلات
3. ابحث باستخدام شريط البحث
4. اضغط على "View Mod" لعرض التفاصيل الكاملة

## 🎯 الصفحات

### الصفحة الرئيسية (index.html)
- عرض جميع التعديلات المتاحة
- تصنيفات وفلاتر سهلة الاستخدام
- شريط بحث متقدم

### صفحة التعديل (game.html)
- تفاصيل كاملة للتعديل
- معلومات التحميل والتقييم
- زر التحميل والمشاركة

### صفحة البحث (search.html)
- نتائج البحث
- ظهور الرسالة عند عدم وجود نتائج
